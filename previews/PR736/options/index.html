Presets

The option preset chooses a set of options together for a sparse model: by default AugmentedPreset on the host and ShiftedPreset on a GPU; CondensedPreset selects the condensed KKT system. The preset chooses the KKT system, unless kkt_system is given, and the options of the linear solver. Options given explicitly take precedence over those of the preset, e.g. madnlp(nlp; preset = ShiftedPreset) selects the shifted setting on the host (with CHOLMOD's LDLᵀ), and madnlp(nlp; preset = ShiftedPreset, barrier = MonotoneUpdate(1e-8, 10.0)) keeps the rest of it with the monotone barrier rule.

MadNLPCore.AbstractPreset — Type
AbstractPreset

A set of options chosen together for a sparse model, given as a type: madnlp(nlp; preset = ShiftedPreset). The preset also chooses the options of the linear solver, through default_options(nlp, preset, kkt_system, linear_solver). Options given explicitly take precedence over those of the preset.

MadNLPCore.ShiftedPreset — Type
ShiftedPreset

The default preset on a GPU: the augmented KKT system factorized LDLᵀ with small pivots bounded, after Ruiz scaling and with a dual shift (both 1e-10 in Float64, see preset_perturbation), each solve refined by GMRES on the unshifted system, with the quality-function barrier rule (QualityFunctionUpdate(sigma_max = 2, mu_decrease_max = 10, mu_min = 1e-3 tol)) and slack reset. On the host the factorization is CHOLMOD's (MUMPS without Julia's GPL libraries), on an NVIDIA GPU cuDSS's; GMRES needs the Krylov package, without which a solve is refined by Richardson iterations. The options beyond the linear solver apply to SparseKKTSystem only. On AMD, Intel and Apple GPUs the factorization is SparseDirectSolver.jl's static LDLᵀ with the same pivot bound.

source
MadNLPCore.AugmentedPreset — Type
AugmentedPreset

The default preset on the host: the augmented KKT system with the default sparse linear solver, its default options and the monotone barrier rule.

source
MadNLPCore.CondensedPreset — Type
CondensedPreset

The condensed KKT system (SparseCondensedKKTSystem): the equality constraints relaxed as pairs of inequalities and the bounds relaxed, with zero initial multipliers, factorized by the same pivot-bounded LDLᵀ as ShiftedPreset (dense rows may be left uncondensed, which keeps the system indefinite), with the monotone barrier rule.

source
MadNLPCore.preset_perturbation — Function
preset_perturbation(T)

The dual shift of ShiftedPreset and the pivot bound of its LDLᵀ factorization, and of CondensedPreset's, in precision T: 1e-10 in Float64. In another precision it is scaled by (eps(T) / eps(Float64))^(5/8), which keeps it at about the same place, on a logarithmic scale, between the unit roundoff and 1 (about 3e-5 in Float32).
