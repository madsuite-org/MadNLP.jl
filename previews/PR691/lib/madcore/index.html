MadCore public API

MadCore provides the KKT systems, the callbacks and the linear solvers on which the interior-point solvers of MadSuite are built. A package built on MadCore should only use the names returned by public_names. Other names are internal and can change in any release.

MadCore.public_names — Function
MadCore.public_names()

Return the names of the public API of MadCore, including the getter and setter of each field in SOLVER_FIELDS. A package built on MadCore imports them to use the API without qualification:

for name in MadCore.public_names()
    @eval import MadCore: $name
end
source

The manipulation of the KKT systems and their right-hand sides is described in KKT systems, and the wrappers around the model in Callback wrappers. The functions below complete these pages.
